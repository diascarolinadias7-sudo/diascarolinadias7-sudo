# Academic Documents Vault

Esta carpeta organiza los documentos académicos y recursos del perfil de GitHub.

## Estructura

```text
docs/
  pptx/
    Prototipo_Wireframes_vs_Mockups_Futurista.pptx
  word/
    Investigacion_Arquitectura_Software_POO_Sistemas_Datos.docx
    Arquitectura_Dinamica_Sistemas_Datos.docx
  pdf/
    README.md
```

## Dónde colocar cada archivo

- `docs/pptx/`: presentaciones de PowerPoint.
- `docs/word/`: documentos de Word.
- `docs/pdf/`: archivos PDF de investigación o documentación académica.

Los enlaces del README principal ya apuntan a estas rutas. Sube los archivos reales con esos nombres para activar los botones y enlaces.
